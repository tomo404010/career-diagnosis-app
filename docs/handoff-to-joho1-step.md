# 「情報Iステップ」への引き継ぎメモ

他の情報I学習アプリ（スクショ17枚）を見て、取り入れたい機能を整理した。
詳しい分析：https://github.com/tomo404010/career-diagnosis-app/blob/claude/upbeat-cerf-ma9cac/docs/joho1-app-reference.md

## 参考にした3タイプ
- ダッシュボード型：総正答率・連続日数・単元別レーダーチャート／全20単元（4分野×5）に講義＋演習・要復習マーク／プログラムを1行ずつ実行（変数表つき）／60分模試（タイマー・問題冊子の拡大）
- ゲーム型：問題の音声連続再生（聞き流し）／単語帳カード／オンライン定期テスト（全国偏差値）／すごろくマップ
- 一問一答型：全問に図つき解説／出題方法を選べる（ランダム・未回答・不正解・ブックマーク）／共通テスト形式（文章・図表・小問をタブ切替）／解答欄ごとに採点＋解説（正解が2つの問題にも対応）

## 取り入れたい機能（優先度順）
★★★ 単元別4択一問一答／不正解だけ再出題・ブックマーク／全問解説（図つき）
★★☆ 進捗ダッシュボード／プログラムを1行ずつ実行する練習（差別化ポイント）／共通テスト形式の大問で解答欄ごとの採点
★☆☆ 聞き流し音声／60分模試／すごろく・称号

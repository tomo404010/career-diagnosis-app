## 1. 参考アプリ別の特徴

### A. 情報Iマスター（ダッシュボード型）※自作中のもの？
- ホーム：総正答率（80%）＋累計解答数＋連続日数（ストリーク）
- 単元別正答率のレーダーチャート（4分野）
- CTA：「練習モードを始める」／「模擬試験へ」
- 全20単元（4分野×5単元）、単元ごとに「講義＋演習」、**要復習マーク**
- 講義は図つき（箱ひげ図など）、拡大ボタン、前へ／次へ
- **プログラム・トレーナー**：1行ずつ実行、実行中の行ハイライト、変数表、空欄ア・イウ形式、保留ボタン
- **60分模試**：本番同構成、残り時間表示、問題冊子の拡大、解答欄（入力済・保留・未回答）

### B. ゲーミフィケーション型（キャラ講師つき）
- 一問一答の**聞き流し（自動音声連続再生）**：速度・間隔の調整
- **単語帳が最初から内蔵**（カードめくり形式）
- **オンライン定期テスト**：全国偏差値・受験者数・賞状風の結果画面・SNS共有
- **すごろく風マップ**で問題を進める、全問クリアでご褒美
- 四択に正解すると次へ進む「ゲーム感覚」

### C. 一問一答＋過去問型（シンプル実用）
- 一問一答584問・11カテゴリー、図表つき問題（論理回路など）
- 進み具合：回答済み／不正解数／ブックマーク数／本日の残り回数
- 出題方法：ランダム／未回答から／不正解から／ブックマークから
- 全問に詳しい解説（図つき）、正解・不正解表示
- 共通テスト形式（試作問題・サンプル問題）、文章・図表・小問をタブ切替
- 無料は1日回数制限 → 購入で無制限・広告なし（課金モデル）

## 2. 自作アプリに「取り入れたい機能」優先順位

| 優先 | 機能 | 理由 |
|---|---|---|
| ★★★ | 一問一答＋4択（単元別） | 基本。授業の小テストにも流用できる |
| ★★★ | 不正解だけ再出題／ブックマーク | 復習効率が段違い。作るのも簡単 |
| ★★★ | 全問解説（図つき） | 通信制の自学自習に必須 |
| ★★☆ | 進捗ダッシュボード（正答率・単元別グラフ・連続日数） | モチベ維持 |
| ★★☆ | プログラム・トレーナー（1行実行＋変数表） | 生徒が一番つまずく分野。差別化ポイント |
| ★☆☆ | 聞き流し音声 | ブラウザの読み上げ機能で実装可 |
| ★☆☆ | 60分模試・タイマー | 問題数がそろってから |
| ★☆☆ | すごろくマップ・称号 | 楽しいがコスト大。後回し |

## 3. 自分ならではの差別化アイデア
- **現役講師が授業で使う前提**：教科書の単元順（20単元）にそろえる
- **通信制向け**：1回5分で終わる「ミニ単元」、スマホ縦画面に最適化
- **先生モード**：クラスの正答率が見られる（将来）
- **note連動**：アプリの解説をnote記事・教材販売に転用

## 4. 次の一手（候補）
1. MVP：単元選択 → 4択一問一答 → 解説 → 不正解復習（Webアプリ）
2. プログラム・トレーナー単体を先に作る（差別化重視）
3. ダッシュボードのデザインだけ先に作って見た目を固める
